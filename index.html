Guía Visual: Transiciones y Animaciones en CSS

Aprende a darle vida e interactividad profesional a tus páginas web utilizando únicamente hojas de estilo, sin necesidad de JavaScript.

1. Transiciones (transition)

Suavizan el cambio entre un estado inicial (A) y un estado final (B). Necesitan un disparador para activarse, como pasar el mouse por encima (:hover) o hacer clic (:focus).

2. Animaciones (@keyframes)

Permiten crear secuencias de movimiento con múltiples pasos. Funcionan de forma automática apenas carga la página y pueden repetirse en bucle infinito (infinite).

Parte 1 • Interactividad con el mouse

Transiciones Sencillas (transition + :hover)

Pasa el cursor sobre cada caja gris

1. Elevación Suave (Lift & Shadow)

Cards / Productos

Ideal para tarjetas de productos o artículos. Eleva el elemento unos píxeles y aumenta su sombra al pasar el cursor.

Pasa el mouse aquí
Código CSS: 
.tarjeta-elevacion {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.tarjeta-elevacion:hover {
  transform: translateY(-6px);
  box-shadow: 0 12px 24px rgba(0, 0, 0, 0.12);
}

2. Zoom Suave en Contenedor

Galerías / Banners

Agranda la imagen sin deformar el diseño gracias a overflow: hidden en la caja contenedora.

Código CSS: 
.caja-imagen {
  overflow: hidden; /* Recorta lo que sobresale */
  border-radius: 12px;
}
.caja-imagen img {
  transition: transform 0.4s ease;
}
.caja-imagen:hover img {
  transform: scale(1.08);
}

3. Botón con Deslizamiento

Botones CTA

Combina un cambio de color de fondo con un ligero desplazamiento horizontal para invitar al clic.

Código CSS: 
.btn-deslizar {
  background-color: #4f46e5;
  transition: background-color 0.3s ease, transform 0.3s ease;
}

.btn-deslizar:hover {
  background-color: #3730a3;
  transform: translateX(4px);
}

4. Subrayado desde el Centro

Menús / Links

Usa el pseudo-elemento ::after y scaleX() para dibujar una línea elegante en enlaces de navegación.

Enlace de Navegación
Código CSS: 
.enlace { position: relative; text-decoration: none; }
.enlace::after {
  content: ''; position: absolute; bottom: 0; left: 0;
  width: 100%; height: 3px; background: #4f46e5;
  transform: scaleX(0);
  transition: transform 0.3s ease;
}
.enlace:hover::after { transform: scaleX(1); }
Parte 2 • Movimiento continuo y de entrada

Animaciones con @keyframes y animation

Se reproducen solas

1. Pulso / Latido

Llama la atención en ofertas, notificaciones o botones principales.

¡Oferta Hoy! 
@keyframes latido {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.06); }
}

.anim-pulso {
  animation: latido 2s ease-in-out infinite;
}

2. Flotación Suave

Da sensación de ingravidez a íconos, logos o ilustraciones. 

@keyframes flotar {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-10px); }
}

.anim-flotar {
  animation: flotar 3s ease-in-out infinite;
}

3. Entrada Gradual

Ideal para títulos al cargar la web. (Mantén clic aquí para repetir).

¡Bienvenido! Fade In Up 
@keyframes aparecer {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
.entrada {
  animation: aparecer 0.8s ease-out forwards;
}

4. Rotación Continua

Útil para indicadores de carga (loaders) o engranajes decorativos. 

@keyframes girar {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

.anim-rotar {
  animation: girar 2.5s linear infinite;
}

3 Reglas de Oro para tus Proyectos con CSS y Bootstrap

1

Evita transition: all

Escribir transition: all 0.3s ease; parece cómodo, pero obliga al navegador a vigilar decenas de propiedades innecesarias y puede chocar con estilos propios de Bootstrap.

Mejor especifica qué animas: transition: transform 0.3s ease, background-color 0.3s ease;

2

No olvides overflow: hidden

Si aplicas transform: scale(1.1) a una imagen dentro de una .card de Bootstrap y no pones overflow: hidden en su contenedor padre, la imagen tapará los bordes redondeados.

Tip Bootstrap: También puedes usar la clase utilitaria overflow-hidden directamente en el HTML.

3

Prioriza transform y opacity

Para mover elementos, usa transform: translateY() en lugar de animar margin-top o top. El navegador acelera transform y opacity usando la tarjeta gráfica (GPU).

Resultado: Animaciones fluidas a 60 FPS incluso en celulares.
