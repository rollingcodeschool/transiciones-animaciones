# Guía Visual: Transiciones y Animaciones en CSS

Proyecto práctico para aprender a crear transiciones y animaciones con HTML5 y CSS3.

## Descripción

Esta página presenta una guía visual sobre el uso de transiciones y animaciones en CSS, con ejemplos reales aplicados a elementos comunes como tarjetas, botones, enlaces y textos. El objetivo es mostrar cómo mejorar la experiencia visual de una interfaz sin necesidad de JavaScript.

Se incluyen ejemplos de:

- Transiciones con `transition` y `:hover`
- Animaciones con `@keyframes`
- Elevación de elementos
- Zoom suave en imágenes
- Subrayados animados
- Pulso, flotación y entrada gradual

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Google Fonts

## Cómo visualizar el proyecto

1. Cloná este repositorio.
2. Abrí el archivo `index.html` en tu navegador.
3. También podés usar una extensión como Live Server para una mejor experiencia de desarrollo.
